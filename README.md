## 一、便宜 VPS 的四笔真实成本，标价只占其中一笔

### 第一笔：线路，带宽数字和国内速度经常是反的

最容易被配置表骗的地方在这里。香港有商家卖 1 核 1G / 15Mbps 三网直连 / 500GB 流量，28 元一个月；同一个商家也卖 1 核 1G / **2Mbps** CN2-GIA / 不限流量，30 元一个月。带宽差了七倍多，价格几乎一样——贵的不是带宽，是那条 GIA 线路。

反过来也成立。香港另一家 1 核 1G / 40G 硬盘 / **1Mbps** / 不限流量 / KVM，一年 238 元，官方页面直接写着：大带宽机型配的是纯国际 BGP 带宽，"中国大陆地区访问延迟高且网络掉包较大，不适合中国大陆访客访问"。

放到美国机房，对比更直观：洛杉矶同城两条产品线，走国际网络、1Gbps 大带宽、1 核 1G / 20G NVMe / 2TB 月流量的年付 $28；改成 200Mbps 但电信 CN2 GIA、联通 AS9929、移动 CMIN2 三网全优的同级配置，年付约 $66。多付三十多美元一年，买的是晚高峰不卡，不是更大的水管。

所以第一件事不是比价，是回答一个问题：**访问你服务器的人在哪。** 国内用户为主，线路优化优先于带宽；海外用户为主、或者你只是拿它当落地机再从中转节点接进来，国际大带宽反而更划算。

### 第二笔：续费价，便宜最容易翻车的地方

"首月十几块、续费上百块"是这行的常规操作，而且往往只限新用户。国内几家的活动价更能说明问题：某老牌云的香港 1 核 1G / 44G / 1M 不限流量曾经做到 84 元一年，明确标注"只有新用户可以享受"；另一家的香港 1 核 2G / 50G 是 375.6 元一年，同样是限时活动。这些价格写在文章里很好看，等你真要买的时候活动早就结束了。

老牌商家也躲不过涨价。搬瓦工那款经典美国 CN2 入门机，从 $19.99 一路涨到 $29.99、$39.99，最后到 $49.99 一年。这个涨价轨迹在各个测评站的说法出奇一致，只有评价两极分化——有人觉得它已经毫无性价比，也有人坚持它的线路最稳。价格是事实，态度是立场，你自己判断。

结论很朴素：**下单前找"续费同价"这四个字。** 找不到，就先买月付，别一上来押年付。

### 第三笔：IP 和售后的隐性账单

IP 被封是便宜 VPS 最常见的售后场景，而各家的处理方式差距很大。有商家规定月付购买时不保证 IP 对大陆可用，想保证得额外加 1 美元；因为个人使用导致 IP 出问题，申请更换 5 美元一次。也有商家把"72 小时内可免费更换一次 IP"写进政策。

这笔钱不大，但它决定了你出问题那天的成本是 0 元还是 5 美元，以及要不要重新配置一遍环境。买之前问三句：能不能换 IP、多少钱一次、免费几次。

### 第四笔：迁移和时间

小商家跑路不是传说。租二手服务器超售资源、开了不到半年就消失的服务商，在这行里年年都有。判断口径也没什么玄学：做了多久、有没有正经的工单系统和中文社群、退款条款写不写得清楚、是否提供月付。这四条都过关，跑路风险至少是可承受的。

## 七、几个买之前一定会问的问题

**便宜 VPS 会不会跑路？**
会，但这跟价格高低不是正相关。判断依据是：有没有正经工单系统和中文社群、退款条款是否白纸黑字、是否提供月付让你先试。丽萨主机有中文帮助中心和 Telegram 交流群，退款条款写明 48 小时无条件，这些是可验证的运营信号；公司主体和运营年限在公开页面里查不到，这一点我不替它补。折中做法就是先用月付。

**年付还是月付？**
先月付，后年付。年付折扣通常在两成到五成之间，丽萨主机这档年付折合每月约 38.8 元、比月付便宜四成多，但代价是流量额度和一次性支出。你至少要用满一个月、确认线路方案稳定，年付的折扣才是真的省下来的钱。

**IP 被墙了怎么办？**
先分清两件事：IP 被封和线路不优化是两码事。原生 IP 不代表不会被封，优化线路也不保证 IP 干净。买之前问清换 IP 的政策和费用——行业里从"72 小时内免费换一次"到"5 美元一次"都有，差别不小。丽萨主机这一组套餐的换 IP 条款建议在下单前通过工单确认。

**要不要为原生 IP 多付钱？**
只在三种情况下要：跑 TikTok 或跨境店铺账号、做流媒体解锁、需要多个干净 IP 做账号矩阵。数据中心 IP 在这类平台的风控里容易被标记，原生 IP 的价值就在这里。反过来，如果你只是搭博客、跑 API、做开发测试，原生 IP 对你的实际体验没有任何提升，那 68 元/月里有一大半是白花的。
